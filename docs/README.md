## 문서 상태

- **제품 기준:** PRD의 P0 요구사항 R01~R10·R17. P1·P2는 백로그에 포함하지 않는다.
- **기술 기준:** Next.js·Supabase 권장안을 제시했지만 팀 승인 전이다. 문서의 API는 구현 기술과 무관한 외부 계약 초안이다.
- **결정 방식:** 팀이 [결정 기록](COLLABORATION.md#결정-기록)을 갱신하면 기술 설계와 백로그를 같은 PR에서 맞춘다.
- **변경 순서:** 사용자 가치나 범위를 바꾸면 PRD를 먼저 수정하고, 기술 상세만 바꾸면 개발 문서를 수정한다.

## 첫 개발 회의에서 확정할 것

1. 웹·서버·DB·파일 저장·이메일 발송·배포 환경.
2. 제작자와 배우의 이메일 인증 방식 및 지원서 재접속 방식.
3. MVP에서 사진 업로드를 허용할 범위와 연기 영상은 링크만 받을지 여부.
4. 시범 운영의 실제 배역·지원자 수와 개인정보 보관·삭제 운영 정책.

이 네 가지가 정해지면 [구현 백로그](IMPLEMENTATION_BACKLOG.md)의 첫 작업을 착수할 수 있다.
