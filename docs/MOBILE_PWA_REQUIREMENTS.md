# 모바일 PWA 사용 경험 요구사항

**상태:** 제품 형태 결정 반영  
**기준:** [PRD](../PRD.md) R17 · [주요 화면 명세](UI_CHAT_SPEC.md)

## 1. 기본 원칙

캐스팅 스와이프는 **제작자와 배우 모두 휴대전화에서 사용하는 PWA**다. 외부 공고의 지원 링크를 누른 배우가 설치 없이 바로 배역을 읽고 지원할 수 있어야 한다. 제작자도 배역 게시, 지원자 검토, 후보 선정과 결과 안내를 휴대전화에서 완료한다. 설치는 반복 사용자를 위한 선택 기능이다.

## 2. 설치와 실행

- HTTPS, 웹 앱 매니페스트, 앱 이름·아이콘·시작 경로·`standalone` 표시 방식을 제공한다. [Next.js PWA 가이드](https://nextjs.org/docs/app/guides/progressive-web-apps), [MDN 설치 조건](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable)
- 홈 화면 설치를 안내하더라도 지원서 제출 전이나 제작자 첫 로그인 전 필수 단계로 만들지 않는다.
- 브라우저에서 연 링크와 설치형 앱에서 연 링크가 **같은 배역 상세**로 연결되어야 한다. 설치 여부로 접근 권한이 달라지지 않는다.
- 설치 안내는 브라우저별로 다르게 처리한다. 일률적인 설치 버튼이 모든 모바일 브라우저에서 작동한다고 가정하지 않는다.

## 3. 모바일 화면 품질

- 세로 화면을 기본으로 설계한다. 본문을 읽기 위해 가로 스크롤이 필요하지 않다.
- 제작자 지원자 목록은 사진·이름·필수 조건 요약·검토 상태·자료 유무를 짧은 행으로 보여주고, 상세는 별도 화면에서 연다.
- 상세에서 뒤로 돌아오면 기존 필터·정렬·스크롤 위치를 유지한다.
- 카드 스와이프를 제공하더라도 `제외`, `보류`, `관심 있음` 버튼을 함께 둔다. 실수한 결정을 되돌릴 수 있다.
- 오디션 일정 제안·응답의 주요 버튼은 메시지 입력창과 혼동되지 않게 구분한다. 현재 확정된 일정을 대화 상단에서 다시 볼 수 있다.
- 화면 키보드가 열릴 때 제출·메시지 전송 버튼이 가려지지 않는지 확인한다.

## 4. 연결 상태와 데이터

- MVP는 **오프라인에서 지원서 제출, 내부 평가 변경, 채팅 전송을 완료하지 않는다.** 연결이 끊기면 `전송되지 않음`과 재시도 방법을 보여준다.
- 입력 중인 지원서와 메시지는 연결 오류 때문에 가능한 범위에서 보존하되, 서버 접수·발송 성공으로 표시하지 않는다.
- 서비스 워커를 사용한다면 앱 셸 등 공개 정적 자산부터 다룬다. 지원자 프로필·사진·메시지·인증 응답을 기본 캐시에 넣지 않는다.
- 설치형 앱 업데이트로 오래된 화면이 남지 않도록 버전 갱신과 재접속 상태를 실기기에서 확인한다.
- 푸시 알림은 후속 기능이다. MVP 결과 안내는 이메일을 기본으로 하고, 알림 권한을 강요하지 않는다.

## 5. 실기기 검증표

| 기기·상태 | 완료할 과업 |
| --- | --- |
| iPhone Safari 브라우저 | 외부 지원 링크 열기 → 배역 읽기 → 지원 완료 → 내 지원 확인 |
| iPhone 홈 화면 설치형 | 로그인 유지·시작 경로·뒤로 이동·지원 현황 확인 |
| Android Chrome 브라우저 | 외부 지원 링크와 제작자 배역 게시·지원자 검토 |
| Android 홈 화면 설치형 | 후보 선정·결과 확정·앱 재실행 |
| 양쪽 기기, 연결 끊김 | 제출·상태 변경·메시지가 성공으로 보이지 않음. 재연결 후 복구 가능 |
| 양쪽 기기, 키보드·긴 목록 | 입력 버튼이 가려지지 않음. 필터와 목록 위치가 유지됨 |

서비스 워커는 설치의 필수 조건이 아니며, 오프라인 기능을 별도로 구현·검증해야 한다. [MDN의 설치 안내](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable)와 [web.dev 서비스 워커 안내](https://web.dev/learn/pwa/service-workers)를 구분해 참고한다.
